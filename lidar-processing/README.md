# Recovered LiDAR Processing Source

This directory contains the original LiDAR-processing source recovered from the public team repository `rahulc07/gset-lidar`.

Original repository: https://github.com/rahulc07/gset-lidar

Related publication: https://ieeexplore.ieee.org/document/10937641

The source in this directory is preserved substantially as originally published so the project record remains accurate. It includes adaptive breakpoint detection, Douglas-Peucker simplification, 2D-to-3D point conversion, convex-hull volume estimation, RPLidar acquisition, and a sensor-angle test script.
